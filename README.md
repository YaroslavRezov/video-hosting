# Anime Video Hosting

A video hosting platform that contains anime videos, similar to [m.wcostream.tv](https://m.wcostream.tv) but with only some of the functionality.

## Killer Feature

### 1. Topic List
A list of topics such as:
- Naruto
- Naruto Shippuden
- One Piece
- Jujutsu Kaisen
- ...

**a.)** Clicking on one leads to the next according list, which is...

### 2. Video List
A list of uploaded videos with names like *"Naruto episode 136"*.

**a.)** Clicking on the name opens a player with one video in it.

**b.)** A button to go back to topics.

### 3. Navigation Buttons
- Buttons that direct to the next or previous videos
- A button that directs to the list of all videos under the topic

### 4. Search Bar
A search bar to search for a title.

## Non-Interfacial

A way to add videos to topics and create topics.
